# Homebrew tap

Formulae for [Wiremux](https://github.com/wiremuxhq/wiremux).

```bash
brew tap wiremuxhq/tap
brew trust wiremuxhq/tap
brew install wiremux
```

Homebrew 6 and later refuse an untrusted tap until `brew trust`.

The formula is updated from the Wiremux release workflow when
`HOMEBREW_TAP_TOKEN` is set on `wiremuxhq/wiremux`.
